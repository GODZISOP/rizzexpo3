# RIZZEXPO — Pet Care System

Interactive DTC pet-care storefront for **RIZZEXPO** featuring:
- **60fps Cursor-Tracked Pixar Dog Hero** (`64` optimized HD WebP frames in `public/frames/` + custom bone cursor)
- **Dark-Charcoal Topographic Editorial UI** with radial product anatomy callouts & crisp white bridging pill cards
- **Real RIZZEXPO Product Catalog**: Eco-Strong Dog Waste Bags + Olive Dispenser, Electrostatic Pet Hair Remover Roller, and Complete Pet Care Duo bundle
- **Slide-Over Cart Drawer**, **Categorized FAQs**, and **Contact Support Hub** (`info@rizzexpo.com`)

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
